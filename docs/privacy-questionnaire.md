# Privacy Questionnaire Answers

Use these answers consistently across Chrome Web Store, Microsoft Edge Add-ons, and Firefox Add-ons privacy forms.

## Data Collection

- Does the extension collect user data? No.
- Does the extension sell user data? No.
- Does the extension share user data with third parties? No.
- Does the extension use analytics or tracking? No.
- Does the extension use advertising identifiers? No.
- Does the extension send data to external servers? No.
- Does the extension execute remote code? No.

## Local Behavior

The extension runs locally in the browser. It receives the URL associated with the context-menu item selected by the user and opens that URL in a focused popup-style browser window.

Unsupported URLs, such as browser-internal pages, are ignored safely.

## Browsing History

The extension does not collect browsing history. It reads only the URL supplied by the browser for the selected context-menu action and does not store or transmit it.

## Bookmarks

Firefox builds request bookmark access so the extension can resolve a selected bookmark context-menu item to a URL for Firefox bookmark context-menu support. It does not scan, collect, store, or transmit bookmarks.

## Cookies And Firefox Containers

Firefox builds request `cookies` and `contextualIdentities` only to preserve the source tab's Firefox container identity when opening a new popup window.

The extension does not read, store, modify, or transmit cookie values.

## Firefox Data Collection Declaration

Data collection: none.
