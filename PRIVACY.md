# Privacy Policy

Open in Basic Window does not collect, store, transmit, or sell user data.

The extension only uses browser extension APIs to add context-menu items and open the selected link, media item, frame, page, tab, or Firefox bookmark in a popup-style browser window.

All behavior runs locally in the browser. The extension does not use analytics, tracking, remote logging, external servers, remote code, advertising identifiers, or third-party data processors.

The extension does not collect browsing history. It reads the URL supplied by the browser for the context-menu item you select only long enough to open that URL in a new popup-style browser window.

Firefox builds request container-related permissions only to preserve the source tab's contextual identity when opening the new window. Those permissions are not used to read, store, or transmit cookie values.
